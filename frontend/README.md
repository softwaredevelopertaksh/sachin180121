# Frontend - React + Next.js

Customer Web Portal for Multi-Vendor E-Commerce Platform

## Features
- Product Browsing & Search
- Shopping Cart & Checkout
- User Authentication
- Order Tracking
- Wishlist Management
- Review & Ratings
- Payment Integration
- Responsive Design

## Tech Stack
- Next.js 13+
- React 18
- Tailwind CSS
- Redux Toolkit
- Axios

## Installation

```bash
npm install
npm run dev
```

## Environment Variables

```
NEXT_PUBLIC_API_URL=http://localhost:3000/api
NEXT_PUBLIC_STRIPE_KEY=your_stripe_key
```

## Project Structure

```
src/
├── app/              # Next.js app directory
├── components/       # Reusable components
├── pages/           # Page routes
├── hooks/           # Custom hooks
├── store/           # Redux store
├── services/        # API services
├── utils/           # Helper functions
└── styles/          # Global styles
```
